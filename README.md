# Mochi Pet

A small transparent desktop pet for macOS and Windows. It is built with Electron, so the same source code can be run and packaged on both platforms.

## What you need

- [Node.js](https://nodejs.org/) 22 LTS or newer
- macOS or Windows

## Run it while developing

1. Open a terminal in this project folder.
2. Install the project dependencies once:

   ```bash
   npm install
   ```

3. Start the pet:

   ```bash
   npm start
   ```

4. Quit it with `Command + Q` on macOS, `Alt + F4` on Windows, or **Close Mochi Pet** in the right-click menu.

`npm start` runs the project from its source files. Use this while changing code or assets; restart the app after editing.

## Make a standalone app

Run the packaging command on the platform you want to distribute to:

| Target | Command | Output |
| --- | --- | --- |
| macOS (Apple Silicon) | `npm run package:mac` | `release/Mochi-Pet-darwin-arm64/Mochi-Pet.app` |
| Windows (64-bit) | `npm run package:win` | `release/Mochi-Pet-win32-x64/` |

Packaging produces an app your friend can run without installing Node.js. It does **not** create one universal file that runs unchanged on both systems: make the macOS build on a Mac and the Windows build on a Windows PC, then share the corresponding output folder. Zip the complete Windows output folder before sending it.

The macOS app is not code-signed or notarized. The first time a recipient opens it, macOS may show a security warning. Windows may similarly show a SmartScreen warning for an unsigned build.

## Pet controls

- **Right-click** the pet to choose its persistent state: Idle, Wave, Sad, Working, or Review.
- **Close Mochi Pet** at the bottom of the right-click menu quits the app.
- **Hover** to play Jump up to three times; leave and hover again to replay it.
- **Left-click and drag** the pet to move it. It uses the matching left/right run animation while dragging.
- The pet uses its Waiting animation while the right-click menu is open.

## Adjust animation speed

Each animation has its own frame interval. In [`renderer/renderer.js`](renderer/renderer.js), edit the `frameIntervalMs` values near the top:

```js
idle: 650,      // slower value = slower animation
jump: 200,
runLeft: 160,
runRight: 160
```

The values are milliseconds per frame. Increase a value to slow that animation down; decrease it to speed it up. Restart the app after saving.

## Project map

```text
assets/              Animation PNGs, grouped by animation
main.cjs             Window, dragging, and native context-menu logic
preload.cjs          Safe bridge between the window and renderer
renderer/            Pet display, animation state, CSS, and timing map
package.json         Commands and dependency versions
```

## For the next developer

- Change animation timing and interaction behavior in `renderer/renderer.js`.
- Change window size, always-on-top behavior, and menu entries in `main.cjs`.
- Keep each animation folder's numbered PNG files continuous from `00.png`.
- Do not edit `node_modules/`; it is generated by `npm install`.
